ArdenTranslator AI —— 使用说明（3 步搞定）

不用装 Python，不用手动拷插件，EXE 里都自带了。


【第 1 步】双击 ArdenTranslatorAI.exe
------------------------------------------------------------
Windows 可能弹一个蓝色警告框，点「更多信息」→「仍要运行」。
只在第一次出现，之后就没有了。


【第 2 步】在管理界面里填 3 项
------------------------------------------------------------
1. 魔兽客户端目录
   点「浏览」，选**能看到 Logs 文件夹**的那一级目录。
   选一次就记住了，以后不用再选。

   传统客户端（ArdenWoW 等）：
       选游戏根目录，就是里面直接有 Interface 和 Logs 的那层。
       例如：D:\yx\wow\ArdenWoW

   启动器套壳客户端（Grimfall 等）：
       选到 resources\Wotlk 那一层。
       例如：D:\yx\wow\Grimfall\Wotlk
       （这个目录里才有 Interface 和 Logs，再往上就没有了）

   分不清就随便选一个：程序会自己往下探 resources\Wotlk。
   选完看管理界面最下面那行状态 —— 显示「等待游戏写入日志」就对了；
   显示「未找到 Logs 目录」就再往上或往下选一层。

2. 模型
   默认 glm-4-flash-250414，不用改。

3. ZHIPU_API_KEY
   去 open.bigmodel.cn 免费注册，在「API Keys」里新建一个、复制，
   粘进这一栏。
   填完可以点右边的「测试模型 + Key」按钮验证一下，通过会提示成功。
   （这个 Key 只保存在你自己电脑的环境变量里，不会写进任何文件。）


【第 3 步】点「开始翻译」
------------------------------------------------------------
程序会自动把插件装进游戏的 Interface\AddOns（每次都会覆盖成最新版），
然后直接弹出翻译悬浮窗。

进游戏，在聊天框打：

    /reload

看到游戏里的英文聊天变成中文显示在悬浮窗里，就成了。


常用操作
------------------------------------------------------------
Ctrl + H        隐藏 / 显示悬浮窗
Ctrl + Q        退出
左上角齿轮 ⚙     按频道屏蔽（不想看哪个就取消勾选）

下次想用，直接双击 ArdenTranslatorAI.exe 就行，所有配置都记住了。


没反应怎么办
------------------------------------------------------------
1. 进游戏打 /atai status，看插件有没有加载
2. 再打 /atai test，看悬浮窗下面的「B:」状态和数字有没有上涨
3. 还是不行：把 ArdenTranslatorAI-check.exe 拖进命令行窗口，
   后面加一个空格和 --check 再回车，把输出发给帮你装的人

【怎么看悬浮窗底部那行状态（v1.1 新格式）】
------------------------------------------------------------
    B:正常 41 · A:等待数据 0 · 已译 31 · 错 0

  B:  实时通道。这个「正常」且数字在涨 = 一切正常。
  A:  备用通道，天生不是实时的（要等游戏自己刷盘，可能几十分钟）。
      长期显示「等待数据 0」是正常的，不影响使用。

  两边的状态词含义：
    未配置      还没选魔兽目录
                文案分三种，看哪一种就知道卡在哪：
                  「未设置客户端目录」        → 还没选目录
                  「未找到 Logs 目录」        → 目录选错层了，重选
                                                （套壳启动器选到 resources\Wotlk）
                  「等待游戏写入日志」        → 目录对了，进游戏就有
    等待数据    装好了但还没收到过消息（游戏没开？没人说话？）
    正常        在正常工作
    45s 无消息  没人说话（正常），或者通道断了
    读取/解析异常  插件和 EXE 版本对不上，两边都重新装一遍

  如果看到「拒 5」这种一直在涨的数字，说明插件和 EXE 版本不匹配，
  用最新版重新点一次「开始翻译」即可。


【给朋友用】把 ArdenTranslatorAI.exe 发过去就行
------------------------------------------------------------
  · 你的 API Key 不会跟着 EXE 走 —— Key 只存在你自己电脑的环境变量里，
    EXE 里不含任何 Key（已用字节级扫描验证过）。
  · 朋友需要自己申请一个智谱 API Key 填进去。
